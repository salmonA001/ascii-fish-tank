# ASCII Fish Tank

A playable remake of the acrylic "digital fish tank" reel: an ASCII fish `><(((o>` swims in a glowing tank and eats the flakes you drop.

- Tap the water to sprinkle a pinch from the FISH FOOD shaker. Hold to keep pouring.
- Grab the shaker and shake it to pour more.

It's one static `index.html` with no build step, so Vercel deploys it as-is.
